01 / THE TRANSFORMATION

Unused does not mean removable.

This program must still fail when divisor = 0. Returning a constant does not authorize dropping an eagerly evaluated division.

Source

input x;
input divisor;
# The unused binding must still fail when divisor is zero.
let unused = x // divisor;
return x * 0;

Baseline IR

%000 = input x
%001 = input divisor
%002 = // %0, %1
%003 = const 0
%004 = * %0, %3
return %4

Optimized IR

%000 = input x
%001 = input divisor
%002 = // %0, %1
%003 = const 0
return %3

The division remains a liveness root. Constants and arithmetic identities may simplify the return value without suppressing an earlier error.

02 / EXECUTABLE SEMANTICS

Three engines. One result—or one error.

Language contract

  • Unbounded signed integers
  • Floor division and divisor-signed remainder
  • Immutable, eager let bindings
  • Left operand evaluated before right
  • All declared inputs validated up front

Verification

Run source through the independent tree interpreter, baseline IR and optimized IR. Compare values and exceptions.

python -m unittest discover -s tests -v

Tests include negative arithmetic, missing inputs, invalid syntax, shared expressions and traps hidden inside unused or zero-multiplied expressions.

A division/modulo instruction can die only when its denominator is proven to be a nonzero constant. Unknown denominators remain observable.
